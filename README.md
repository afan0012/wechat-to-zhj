# 微信群订单 → 金蝶智慧记

做批发的老板，客户每天在微信群里发单：「鸭肉卷50件×147.5」「再加5件鸡柳」「那单鸡腿改成15件」。以前得一张张手敲进金蝶智慧记。

这个工具把群聊复制下来交给 AI，按客户整理成销售单，然后直接写进智慧记。库存和欠款由智慧记自己算。

```
群聊文本 ──► parse_orders.py ──► 核对表.xlsx + 解析结果.json ──► import_to_zhj.py ──► 智慧记销售单
            （DeepSeek 解析）       （人看一眼拿不准的）            （先校验，再写入）
```

## 能认出什么

- 同一个客户当天的多条消息（包括后面「再加」「补」的）合并成一张单
- 后面的改价、改数量覆盖前面的值
- 群里的简称、别名、错别字对到系统里的正式货品名（「牛丸」→撒尿牛丸，「金龙鱼油」→金龙鱼大豆油），有规格区分的选对规格
- 「十件」「两箱」转成数字
- 赠品单独一行，单价 0，库存照样扣
- 送货、付款、补货这类说明写进备注
- 新客户、系统里没有的货品、「按老价」这类拿不准的，写进 warnings 让人确认
- 「收到」「几点送」这种闲聊直接忽略

## 实测

用 `make_test_data.py` 生成的模拟数据（15 个货品、7 个客户、一天的群消息）跑了一遍：7 张单一次写进智慧记 V7.2，新客户「小美便利店」被跳过并提示先建档，系统里没有的「雪花啤酒」没录，写进了备注。核对的几个库存都对得上（比如酱油 500 → 211：卖出 200，赠送 89）。

## 用法

```bash
pip install openai xlrd xlwt openpyxl
export DEEPSEEK_API_KEY=sk-xxx

python make_test_data.py                                   # 生成测试数据（可选）
python parse_orders.py 2_微信群消息_10-21.txt              # 货品/客户从测试 xls 读
python parse_orders.py 消息.txt --db "<智慧记目录>/zhjd/data.db"   # 货品/客户从智慧记数据库只读

python import_to_zhj.py output/解析结果.json --db "<智慧记目录>/zhjd/data.db"            # 只校验，不写入
python import_to_zhj.py output/解析结果.json --db "<智慧记目录>/zhjd/data.db" --commit   # 校验通过后写入
```

写入前智慧记要开着。

## 为什么不模拟鼠标点

最早打算用 pywinauto 模拟点「导入」按钮，但智慧记是以管理员权限运行的，普通程序操作不了它的界面。

后来发现智慧记自带一个本地服务 `zhjd`，监听 `127.0.0.1:5166`，它自己的界面就是通过这个服务开单的。`import_to_zhj.py` 调的是同一套接口：`sale.chk` 校验，`sale.i` 保存。效果和在界面上点「保存」一样，库存、应收款都由智慧记自己算，不直接改数据库。数据库只读，用来把货品代码、客户名换成内部 id。

## 注意

- **这不是金蝶官方开放的接口**，是从智慧记自己的运行日志里看出来的。只在 V7.2 上测过，别的版本或升级之后可能不能用。换一台电脑，先用「只校验」模式跑一遍。
- 「货款已付」现在不会自动记成已收款，单子一律记欠款。要记收款，需要再指定收款账户，这条规则得按你自己的记账习惯加。
- 正式用之前，拿一天的真实单子对一遍核对表，确认准确率再 `--commit`。
- 自己承担使用风险，建议先备份账套。

## 不想写代码的版本

如果只是想省掉手敲，不需要这些脚本：把群聊复制给豆包、WorkBuddy 这类 AI，让它按智慧记「销售单 → 导入」的 Excel 模板（4 列：货品代码、品名规格、数量、原价），每个客户生成一个表。然后在智慧记里选好客户，点「导入」选这个表。这个导入实测可以用。

注意导入之后「本次实收」默认等于全额，记账没收钱的单子，保存前要改成 0。

给 AI 的提示词：

```
我是做食品批发的，下面是客户今天在微信群里发的订货单，请帮我整理成智慧记的导入表格。

规则：
1. 按客户分开，同一个客户当天的所有订货（包括后面"再加""补"的）合并成一张单。
2. 后面有改价、改数量的消息，以最后一条为准。
3. 品名必须用我商品列表里的名字，一字不差；群里写的是简称或别名，按意思对上（比如"牛丸"对"撒尿牛丸"）。列表里找不到的不要写进表格，单独告诉我。
4. 数量写阿拉伯数字（"十件"写10），箱和件算同一个。
5. 消息里写了单价就用这个价；没写就用商品列表里的批发价。
6. 送的赠品单独一行，单价写0。
7. "收到""几点送"这类闲聊不用管。

输出：
- 每个客户生成一个 Excel 文件，文件名是"客户名_日期"。
- 表格只有4列，第一行表头必须是：货品代码、品名规格（必填）、数量、原价。
- 最后给我一个清单：每张单的客户、合计金额、备注（送货、付款、补货这些说明），还有拿不准需要我看一眼的地方。
```

第一次用之前，先把智慧记里的商品列表（货品资料导出成 Excel）发给 AI，告诉它「这是我的商品列表，以后都按这个对」。
